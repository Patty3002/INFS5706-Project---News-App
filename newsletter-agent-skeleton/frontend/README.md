# Frontend skeleton

## Local setup

From this directory:

```bash
npm install
npm run dev
```

The frontend intentionally renders only a static placeholder. No API calls or user-interface functionality has been implemented.

## Planned areas

- `api/`: future backend client modules
- `components/`: reusable interface components
- `pages/`: onboarding, preferences, preview, and settings screens
- `styles/`: shared styling
